Herramientas de cámara

Una prueba manual con las credenciales que indiques. No se guardan ni se incluyen en CSV. Una página pública no confirma la contraseña. Algunas cámaras requieren un usuario ONVIF propio o la hora sincronizada. Evita repetir pruebas con datos incorrectos para no bloquear la cuenta. HTTP Basic puede enviar la clave sin cifrado dentro de la red local de la cámara.

Preparar el acceso no abre puertos. El túnel se inicia cuando ejecutas el comando en tu computadora y termina con Ctrl+C.
