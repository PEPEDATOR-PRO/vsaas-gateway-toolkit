Abrir panel del colector ↗

Pulsa Consultar estado. La consulta requiere acceso administrativo de Cockpit.

Entrar por primera vez

  1. Consulta el estado y abre el panel en una pestaña nueva. El acceso utiliza la IP VPN de este Gateway.
  2. En la terminal del Gateway ejecuta sudo vsaas-eventos llave. Copia la llave en el panel del colector y pulsa Conectar.
  3. Agrega una cámara con su dirección ONVIF, usuario y contraseña. Las cámaras de Vsaas no se importan automáticamente.
  4. Genera un evento de prueba y confirma que aparece en el historial. Una respuesta HTTP correcta no confirma que las cámaras estén enviando eventos.

Para acceso de solo lectura utiliza sudo vsaas-eventos llave-consulta. Las llaves son distintas y se generan localmente.

Captura e historial

ONVIF PullPoint, pista RTSP/TCP de metadatos cuando el equipo la ofrece y entrada HTTP con token por cámara. No se graba video.

Cerrar esta página no detiene el servicio. El colector continúa en Docker y recupera su configuración al arrancar. Pausar la vista del panel solo detiene su actualización visual.

El módulo usa límites de recursos y un presupuesto preventivo de 1 GiB para eventos. Si no puede guardar más datos, conserva el historial y muestra un error de almacenamiento. No borra automáticamente eventos. Revisa el espacio y exporta los registros necesarios.

Para detener la captura: sudo systemctl stop vsaas-eventos. Para recuperarla: sudo systemctl start vsaas-eventos.
